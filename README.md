CSV Data Analyzer
📌 Description
A beginner-friendly Python project that loads and analyzes CSV files using Pandas.  
It helps inspect data structure, summary statistics, and missing values.
🛠 Technologies Used
Python
Pandas
🚀 Features
Reads CSV files
Displays first 5 rows
Shows statistical summary
Detects missing values
Sample Data
This repository includes a sample CSV file (`data.csv`) created for demonstration and testing purposes.  
The data represents realistic personal expense records and does not contain any real or sensitive information.
▶ How to Run
Install Python
Install Pandas:
pip install pandas(in CMD run as admin)
Run:
python csv_analyzer.py
